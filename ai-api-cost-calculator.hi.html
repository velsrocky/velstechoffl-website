AI API लागत कैलकुलेटर

क्लाउड API लागतों की तुलना स्थानीय इन्फ़रेंस से करें

क्लाउड API बनाम अपने स्वयं के हार्डवेयर पर अपना वर्कलोड चलाने में कितनी लागत आती है? अपना दैनिक टोकन उपयोग दर्ज करें और OpenAI, Anthropic, Google के लिए मासिक लागत और स्थानीय रूप से चलाने की अनुमानित बिजली लागत देखें।

कीमतें अनुमानित हैं और बार-बार बदलती हैं। API मूल्य निर्धारण प्रत्येक प्रदाता की प्रकाशित दरों से लिया गया है। स्थानीय लागत 100% GPU उपयोग मानती है। पूर्ण तुलना के लिए स्थानीय बनाम क्लाउड AI गाइड देखें।
