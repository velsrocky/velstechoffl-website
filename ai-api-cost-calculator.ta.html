AI API செலவு கால்குலேட்டர்

கிளவுட் API செலவுகளை உள்ளூர் inference உடன் ஒப்பிடுங்கள்

உங்கள் பணிச்சுமையை கிளவுட் API வழியாக இயக்குவதற்கு எவ்வளவு செலவாகும், உங்கள் சொந்த வன்பொருளில் இயக்குவதற்கு எவ்வளவு? உங்கள் தினசரி டோக்கன் பயன்பாட்டை உள்ளிட்டு, OpenAI, Anthropic, Google க்கான மாதாந்திர செலவுகளையும், உள்ளூரில் இயக்குவதற்கான மதிப்பிடப்பட்ட மின்சார செலவையும் பாருங்கள்.

விலைகள் தோராயமானவை மற்றும் அடிக்கடி மாறும். API விலைகள் ஒவ்வொரு வழங்குநரின் வெளியிடப்பட்ட விகிதங்களிலிருந்து எடுக்கப்பட்டவை. உள்ளூர் செலவு 100% GPU பயன்பாட்டை கருதுகிறது. முழுமையான ஒப்பீட்டிற்கு உள்ளூர் vs கிளவுட் AI வழிகாட்டியைப் பார்க்கவும்.
