About this result

IQ2_XS-mtp carries blk.64.nextn.* MTP tensors but no MTP flag was passed, so they are ignored – both runs are plain decode. IQ2_XS wins decode (+9%) and fits 52K ctx with q8_0 KV under --fit; IQ3_S wins prompt eval (+57%) but --fit aborted because -ngl 999 was set by hand, leaving the default 4K ctx. Drop -ngl (or raise -c) to let --fit size IQ3_S properly.

This result was tested in the VelsTech Lab on real hardware.
