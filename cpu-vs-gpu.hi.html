CPU vs GPU – प्रत्येक क्या करता है?

Components Basics Aug 24, 2026 · 5 मिनट का पठन

हर कंप्यूटर में CPU और GPU दोनों होते हैं, लेकिन वे बहुत अलग प्रकार के काम के लिए बने हैं। यहाँ एक सरल उपमा है जो दोनों को समझाती है।

किचन वाली उपमा

एक रेस्टोरेंट की किचन की कल्पना करें।

CPU हेड शेफ है। वह जटिल रेसिपी को एक बार में एक – या कुछ एक साथ, तेज़ी से बदल-बदल कर – फॉलो करने में माहिर है। उसे कोई मुश्किल सॉस, नाज़ुक टाइमिंग का मामला, या कई चरणों वाली गणना दें, और वह उसे सटीकता से संभाल लेगा।

GPU सौ किचन सहायकों जैसा है जो सब्ज़ियाँ काट रहे हैं। प्रत्येक सहायक केवल एक सरल काम कर सकता है – एक गाजर काटना – लेकिन वे सभी एक ही समय पर कर सकते हैं। उन्हें कोई ऐसा कार्य दें जो एक ही ऑपरेशन को हज़ारों बार दोहराता हो, और वे उसे सेकंडों में पूरा कर देंगे।

CPU – कुछ, तेज़, स्मार्ट वर्कर। GPU – हज़ारों सरल वर्कर जो समानांतर में काम करते हैं।

CPU क्या करता है

CPU general-purpose दिमाग है। यह संभालता है:

  • ऑपरेटिंग सिस्टम चलाना
  • एप्लिकेशन खोलना और मैनेज करना
  • वेब ब्राउज़िंग, फ़ाइल हैंडलिंग, system logic
  • single-threaded कार्य जैसे audio processing, compression
  • अन्य सभी घटकों में समन्वय

CPU में कुछ शक्तिशाली cores होते हैं (अधिकांश consumer चिप्स में 4–16), प्रत्येक जटिल, क्रमिक कार्य के लिए अनुकूलित। तेज़ CPU आपके कंप्यूटर को तेज़ महसूस कराता है।

GPU क्या करता है

GPU एक विशेषीकृत parallel processor है। यह इनमें माहिर है:

  • ग्राफ़िक्स रेंडर करना – आपकी स्क्रीन के हर pixel को 60+ बार प्रति सेकंड ड्रॉ करना
  • मशीन लर्निंग – neural networks को train और run करना (बड़े पैमाने पर matrix math)
  • वीडियो encoding/decoding, 3D rendering, simulation
  • कोई भी कार्य जो “लाखों data points पर वही काम करना” हो

आधुनिक GPU में हज़ारों छोटे cores होते हैं (NVIDIA पर CUDA cores, AMD पर Stream Processors)। प्रत्येक core अकेले में कमज़ोर है, लेकिन साथ मिलकर वे embarrassingly parallel workloads को कुचल देते हैं।

Integrated vs Dedicated

कई CPU में एक छोटा GPU बना होता है (integrated graphics)। यह वेब ब्राउज़िंग, वीडियो और हल्के creative कार्य के लिए ठीक है – लेकिन आधुनिक गेम अच्छे से नहीं चलाएगा।

dedicated GPU अपनी खुद की memory और cooling वाला अलग कार्ड है। गेमिंग, rendering या AI कार्य के लिए यही चाहिए।

क्या वे साथ काम कर सकते हैं?

हाँ। आधुनिक system में, CPU draw commands को GPU को भेजता है, और GPU उन्हें execute करता है। CPU “क्या ड्रॉ करना है” और game logic संभालता है; GPU “हर pixel को कैसे ड्रॉ करना है” संभालता है। वे प्रतिस्पर्धी नहीं हैं – वे साथी हैं।

bottleneck वही है जो अपना काम धीरे पूरा करता है। बहुत तेज़ GPU के साथ कमज़ोर CPU का अर्थ है कि CPU commands को तेज़ी से feed नहीं कर पाता (CPU bottleneck)। बहुत तेज़ CPU के साथ कमज़ोर GPU का अर्थ है कि GPU साथ नहीं दे पाता (GPU bottleneck)। संतुलित builds का लक्ष्य होता है कि कोई भी bottleneck न हो, हालाँकि गेमिंग में हल्का GPU bottleneck सामान्य और ठीक है।

निष्कर्ष

CPU आपके कंप्यूटर का दिमाग है; GPU parallel कार्य के लिए उसकी मांसपेशी है। आपको दोनों चाहिए, और कौन अधिक मायने रखता है यह पूरी तरह इस बात पर निर्भर करता है कि आप क्या कर रहे हैं। अधिकांश लोगों के लिए, decent GPU (या non-gaming build के लिए integrated graphics) के साथ mid-range CPU सही संतुलन है।
