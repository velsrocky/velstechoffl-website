CPU மற்றும் GPU விவகாரம்: அவை என்ன செய்கின்றன?

பகுதிகள் அடிப்படைகள் Aug 24, 2026 · 5 நிமிட வாசிப்பு

ஒவ்வொரு கணினியிலும் ஒரு CPU மற்றும் ஒரு GPU உள்ளன, ஆனால் அவை பல வேறுபட்ட வகையான பணிகளுக்காக உருவாக்கப்பட்டுள்ளன.

சமையலறை ஒப்பாய்வு

ஒரு உணவகத்தின் சிற்றறை

அவர் CPU தலை பாத்திரப் பொறுப்பாளர். ஒரு சமயத்தில் ஒரு செய்முறையையும் மற்றொரு சமயத்தில் மற்றொரு செய்முறையையும் வேகவைப்பதில் அவர்கள் சிறப்பானவர்கள். அவர்களுக்கு ஒரு சிக்கலான சாஸ், ஒரு தெளிவான நேர பிழை, அல்லது ஒரு பல கடின கணிதம், அவர்கள் அதை தெளிவாக செய்யும்.

அவர் GPU நூறு உணவக உதவியாளர்கள் காய்கறிகளை நறுக்குகின்றனர். ஒவ்வொரு உதவியாளரும் ஒரு சின்ன வேலையையே செய்யவும் கூடியது - ஒரு கத்தரியை வெட்டுவது போன்றது - ஆனால், அவை அனைத்தும் ஒரே நேரத்தில் அதைச் செய்ய முடியும். அவர்களுக்கு ஒரு பணியை கொடுத்தால், அதே செயலை ஆயிரம் முறை மற்றும் அதற்கு மேற்பட்ட முறைகள் மேற்கொள்ள வேண்டும், அவர்கள் அடிக்கடி நொடிகளில் முடிக்கலாம்.

CPU: சில, வேகமான, தெளிவான பணியாளர்கள். GPU: பல எளிய பணியாளர்கள் சமச்சீரான பட்டையில்.

What the CPU does

CPU என்பது பொதுவான நரம்புத்தகைமைஅது செய்கிறது:

  • இயங்கும் இயங்கு முறைமையை ஓட்டுதல்
  • அப்ளிகேஷன்களை திறக்கும் மற்றும் மேலாண்மை செய்தல்
  • வலை பரிசீலனை, தர பாதுகாப்பு, செயல்திட்ட யாபகம்
  • ஒரு தட்டைக்கற்றை பணிகள் போன்றவைகள் ஒலி செயலாக்கம், அழுத்தம்.
  • அனைத்து மற்ற தகுந்த பகுதிகளையும் ஒருங்கிணைத்தல்.

CPU களில் சில சக்திவாய்ந்த கோர்கள் (4–16 பெரும்பாலான பயன்பாட்டு சிப்களில்), ஒவ்வொன்றும் சிக்கலான, முழுமையான பணிகளுக்கு ஒத்திசைக்கப்பட்டுள்ளது. விரைவான ஒரு CPU உங்கள் கணினியை உணர்த்துகிறது முக்கிய.

What the GPU does

GPU என்பது ஒரு தனிப்பட்ட சமநிலை செயலிகர். அது சிறப்பாக செயல்படுகிறது:

  • வெளிப்படை உருவாக்கம் - உங்கள் படம் அனைத்து பிக்ஸ்லையும் ஒரு வினாடிக்கு 60+ முறையாக வரைதல்
  • மொசின் கற்றல் – தருவாய் மற்றும் ஓட்டும் நரம்பு நாளுக்கு நாள் நெட்வர்க்குகள் (மேற்பரப்பு அளவு மேற்புள்ளி கணிதம்)
  • வீடியோ என்கோடிங்/டிஜிட்டல், 3D ரென்டரிங், சிமுலேஷன்
  • மில்லியன் தரவு புள்ளிகளுக்கு "அதே செயலை செய்யுங்கள்

ஒரு மாற்றுத்திறன் பிசி (GPU) ஆபிஸ் ஆயிரக்கணக்கண் சிறிய கருவூலங்களை (CUDA கருவூலங்கள் NVIDIA-ல், Stream Processors அம்டி-ல்) கொண்டிருக்கும். ஒவ்வொரு காரினும் தனித்தனியாகவே பலமற்றது; ஆனால் சேர்ந்து அழுத்தமான பல பணிகளை அழிக்கும்.

Integrated vs dedicated

பல சிப்பு முறைகளில் ஒரு சிறிய ஜிபியை உள்ளடக்கியுள்ளது (சேர்க்கப்பட்ட வரைபடம்) சரியாகவே வலைப் பயணம், வீடியோ, மற்றும் கனவுறா கலைப் பணிகளுக்குப் பயன்படுகிறது – ஆனால் இது முழுமையான விளையாட்டுகளை நன்றாக ஓட்ட முடியாது.

A தனிப்பட்ட ஜிபியூ தனியான கார்டு இதனுடன் தனியான நினைவகமும் குளிர்சாதனமும் இருக்கும். இது விளையாட்டு, ரென்டரிங் அல்லது ஏஐ வேலைகளுக்கு தேவையானது.

அவர்கள் ஒன்றாக செயல்படலாமா?

ஆம். ஒரு புதிய அமைப்பில், சிபி யூ (CPU) வரைவு உத்தரவுகளை ஜிபி (GPU) ஐ அனுப்புகிறது, மேலும் ஜிபி (GPU) அவற்றை நிறைவேற்றுகிறது. சிபியூ அனுபவம் என்ன வரையப்படுகிறது என்பதும், விளையாட்டு கணித்தனுபவம்; ஜிபியூ என்ன வரையப்படுகிறது என்பதும். அவர்கள் போட்டியாளர்கள் அல்ல - அவர்கள் கூட்டாளிகள்.

அடுத்தபடியாக ஒரு சிக்கல் அதுவே ஆகும். ஒரு சிறந்த ஜிபியை உடைய ஒரு கணினி ஒரு சிறு சிப்புக்காக போராடுகிறது.சிபியூ அடக்கம்) ஒரு சாதாரண வேகமான CPU உடன் தளர்ந்த GPU என்பதால், GPU தனது செயல்திறனை கண்டிப்பாகக் காட்ட முடியாது.GPU அடிப்படையில் அடப்படுதல்) . சமநிலை கட்டமைப்புகள் சாதாரண தடையை நோக்கமாகக் கொள்வதில்லை, ஆனால் விளையாட்டிற்கு, சிறிய கிராபிக்ஸ் பாதிப்பு சாதாரணமானது மற்றும் சரியானது.

இறுதி விளைவு

CPU உங்கள் கணினியின் மனம்; GPU உங்கள் கணினியின் சமரச பணிக்கு இரத்தம். நீங்கள் இரண்டையும் தேவைப்படுகிறீர்கள், மற்றும் எந்த செயல்பாடு செய்கிறீர்கள் என்பதைப் பொறுத்தே அது மேலானது என்பது முழுமையாக தீர்மானிக்கப்படுகிறது. பெரும்பாலான மக்களுக்கு, ஒரு இடைநிலை சி.பி.யு (CPU) மற்றும் ஒரு மிகவும் நல்ல GPU (அல்லது இணைக்கப்பட்ட கிராபிக்ஸ் பலகைகள் போன்ற போக்குகள்) சரியான சமநிலையைக் கொண்டுள்ளது.
