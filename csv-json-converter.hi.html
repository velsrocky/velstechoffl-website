CSV ↔ JSON कन्वर्टर

CSV और JSON के बीच कन्वर्ट करें · हेडर पंक्ति आवश्यक है · आपके ब्राउज़र में चलता है

एक CSV (कॉमा, टैब या पाइप-सेपरेटेड) पेस्ट करें और तुरंत एक साफ़ JSON ऐरे प्राप्त करें। यह दूसरे तरीके से भी काम करता है: ऑब्जेक्ट का JSON ऐरे पेस्ट करें और CSV प्राप्त करें। कोई डेटा किसी भी सर्वर को नहीं भेजा जाता – सब कुछ आपके ब्राउज़र में स्थानीय रूप से चलता है।
