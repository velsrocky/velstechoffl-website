CSV ↔ JSON Converter

Convert between CSV and JSON · header row required · runs in your browser

Paste a CSV (comma, tab, or pipe-separated) and instantly get a clean JSON array. Works the other way too: paste a JSON array of objects and get CSV. No data is sent to any server – everything runs locally in your browser.
