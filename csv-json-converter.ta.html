CSV ↔ JSON மாற்றி

CSV மற்றும் JSON இடையே மாற்றவும் · தலைப்பு வரி தேவை · உங்கள் உலாவியில் இயங்குகிறது

CSV (கமா, டேப் அல்லது பைப்பால் பிரிக்கப்பட்டது) ஒட்டி உடனடியாக சுத்தமான JSON அணியைப் பெறுங்கள். எதிர் திசையிலும் வேலை செய்கிறது: பொருள்களின் JSON அணியை ஒட்டி CSV பெறுங்கள். எந்த தரவும் சேவையகத்திற்கு அனுப்பப்படுவதில்லை – அனைத்தும் உங்கள் உலாவியில் உள்நாட்டில் இயங்குகிறது.
