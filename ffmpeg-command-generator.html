FFmpeg Command Generator

Build a correct ffmpeg command without memorizing flags

Set the format, codec, quality, and trim times and this builds the full ffmpeg command for you – with a plain-English explanation of what each part does. Copy it straight into your terminal.

H.264/5 use CRF for quality (lower = better, 18–28 typical); VP9/AV1 often use -crf with -b:v 0 for quality-based encoding. Audio-only formats (MP3/Opus/WAV) skip video settings automatically.
