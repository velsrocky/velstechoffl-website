உங்கள் முதல் PC கட்டுமானத்திற்கான பாகங்களை எப்படி தேர்ந்தெடுப்பது

PC கட்டுமானம் வழிகாட்டி Aug 24, 2026 · 8 நிமிட வாசிப்பு

உங்கள் முதல் PC ஐ உருவாக்குவது பயமாக இருக்கிறது, ஒன்றை உணரும் வரை: ஒவ்வொரு பாகமும் ஒரே கேள்விக்கு பதிலளிக்கிறது – இந்த கணினியை வைத்து என்ன செய்யப் போகிறீர்கள்? முதலில் அதை முடிவு செய்யுங்கள், பாகங்கள் தங்களைத் தாங்களே தேர்ந்தெடுத்துக் கொள்ளும்.

படி 0: கட்டுமானத்தை வரையறுக்கவும்

உங்கள் முதன்மை பயன்பாட்டைப் பற்றி நேர்மையாக இருங்கள். இது உங்கள் பட்ஜெட் எங்கு செல்கிறது என்பதை தீர்மானிக்கிறது:

  • கேமிங் → பட்ஜெட்டில் பெரும்பகுதி GPU க்கு.
  • நிரலாக்கம் / பொது வேலை → சமநிலையானது, ஒரு நல்ல CPU முக்கியம்.
  • வீடியோ எடிட்டிங் / 3D → வலுவான CPU + GPU + நிறைய RAM.
  • அலுவலகம் / வலை உலாவல் → ஒரு எளிமையான கட்டுமானம் உடனடியாக உணரும்.

வலை உலாவலுக்காக "எதிர்கால-ஆதார" அரக்கனை உருவாக்காதீர்கள் – பயன்படுத்தப்படாத பாகங்களுக்கு அதிக செலவு செய்வீர்கள்.

1. CPU: மூளை

இரண்டு பிராண்டுகள் ஆதிக்கம் செலுத்துகின்றன: AMD மற்றும் Intel. பெரும்பாலான முதல் கட்டுமானங்களுக்கு, இரண்டு பிராண்டுகளின் தற்போதைய நடுத்தர வரம்பு போதுமானதை விட அதிகம். ஒரு எளிய மன மாதிரி:

  • Ryzen 5 / Core i5 – கிட்டத்தட்ட அனைவருக்கும் சிறந்த இடம்.
  • Ryzen 7 / Core i7 – கனமான பல்பணி, ஸ்ட்ரீமிங், ரென்டரிங்.
  • Ryzen 3 / Core i3 – பட்ஜெட் கட்டுமானங்கள், அலுவலக வேலை, இலகு கேமிங்.
சாக்கெட்டை சரிபார்க்கவும்! CPU மதர்போர்டு சாக்கெட்டுடன் பொருந்த வேண்டும். நீங்கள் முதலில் CPU ஐ தேர்ந்தெடுத்தால், மதர்போர்டு அடுத்தது வரும் – அது சாக்கெட் மற்றும் உங்கள் மற்ற பாகங்கள் இரண்டிற்கும் பொருந்த வேண்டும்.

2. மதர்போர்டு: முதுகெலும்பு

மதர்போர்டு எல்லாவற்றையும் இணைக்கிறது மற்றும் உங்கள் மேம்படுத்தல் பாதையை ஆணையிடுகிறது. பொருத்த வேண்டிய மூன்று விஷயங்கள்:

  • சாக்கெட் – உங்கள் CPU உடன் பொருந்த வேண்டும்.
  • RAM வகை – DDR4 அல்லது DDR5; நீங்கள் வாங்கும் ஒன்றை ஆதரிக்கும் போர்டைப் பெறுங்கள்.
  • படிவ காரணி – ATX (முழு அளவு), micro-ATX, அல்லது mini-ITX. இது உங்கள் கேஸுக்கு பொருந்துவதை உறுதிசெய்யுங்கள்.

முதல் கட்டுமானத்திற்கு, போதுமான USB போர்ட்கள் மற்றும் M.2 ஸ்லாட்கள் கொண்ட ஒரு திடமான நடுத்தர வரம்பு போர்டு உங்களுக்கு போதுமானது. உயர்நிலை "கேமிங்" போர்டுகள் உங்களுக்கு தேவையில்லை.

3. RAM: நீங்கள் நினைப்பதை விட அதிகம்

விதி மாறிவிட்டது: 16 GB என்பது புதிய குறைந்தபட்சம், 32 GB வசதியானது. உலாவிகள், அப்ளிகேஷன்கள் மற்றும் விளையாட்டுகள் நீங்கள் எதிர்பார்ப்பதை விட வேகமாக நினைவகத்தை உண்கின்றன.

  • 16 GB – இன்று கேமிங் மற்றும் பொது பயன்பாட்டிற்கு நல்லது.
  • 32 GB – எடிட்டிங், விர்ச்சுவலைசேஷன், கனமான பல்பணி, "எதிர்கால-ஆதாரம்".
  • வேகம் – உங்கள் CPU/மதர்போர்டு ஆதரிக்கும் வேகத்தில் RAM வாங்கவும். அதிக GB > அதிக வேகம்.

கலந்த அளவுகளை வாங்குவதை விட பொருந்திய கிட் (இரண்டு ஒத்த ஸ்டிக்குகள்) வாங்குவது சிறந்தது, ஏனெனில் அது டூயல்-சேனல் முறையில் இயங்குகிறது – திறமையாக வேகமான நினைவக அணுகல்.

4. சேமிப்பு: எப்போதும் முதலில் SSD

இது மிகப்பெரிய வாழ்க்கை-தர முடிவு. HDD மட்டுமே கொண்ட PC ஐ ஒருபோதும் உருவாக்க வேண்டாம். OS க்கான NVMe SSD எல்லாவற்றையும் உடனடியாக உணர வைக்கிறது. 

1 TB NVMe SSD  ->  operating system + programs + games
2 TB HDD       ->  (optional) bulk storage for backups and media

பட்ஜெட் இறுக்கமாக இருந்தால், SSD பெறுங்கள் மற்றும் HDD ஐத் தவிர்க்கவும். பின்னர் சேமிப்பகத்தைச் சேர்க்கலாம்; ஸ்பின்னிங் டிரைவுடன் பூட் டிரைவாகத் தொடங்குவது மிகவும் பொதுவான வருத்தம்.

5. GPU: கேமிங்கின் மிகப்பெரிய வீரர்

நீங்கள் கேமிங் செய்கிறீர்களோ அல்லது GPU-கனமான வேலை செய்கிறீர்களோ, உங்கள் பணம் செல்லும் இடம் இதுவே. NVIDIA மற்றும் AMD இரண்டும் ஒவ்வொரு நிலையிலும் சிறந்த கார்டுகளை உருவாக்குகின்றன:

  • நுழைவு – 1080p கேமிங், esports தலைப்புகள்.
  • நடுத்தர வரம்பு – சிறந்த இடம்: உயர் அமைப்புகளில் 1080p/1440p.
  • உயர்-நிலை – 4K, ரே டிரேசிங், கனமான ரென்டரிங்.

கார்டை உங்கள் மானிட்டரின் ரெசல்யூஷனுடன் பொருத்துங்கள். பட்ஜெட் GPU உடன் 4K மானிட்டர் வீணான பணம், மேலும் 1080p மானிட்டரில் ஒரு அரக்கன் GPU என்பது நீங்கள் செலவிட வேண்டியதில்லாத பணம்.

ஒருங்கிணைந்த கிராபிக்ஸ் கொண்ட CPU இருந்தால், கேமிங் அல்லாத கட்டுமானத்திற்கு GPU ஐ முழுவதுமாகத் தவிர்க்கலாம் – அது ஒரு சிறந்த பட்ஜெட் நகர்வு.

6. "AI PC" கேள்வி

இன்றைய ஒவ்வொரு CPU யும் தன்னை AI உடன் சந்தைப்படுத்துகிறது. எது உண்மையானது, எதை புறக்கணிக்கலாம் என்பது இதோ. நவீன சிப்புகளில் ஒரு NPU (நரம்பியல் செயலாக்க அலகு) அடங்கும் – அழைப்புகளில் பின்னணி மங்கல், நிகழ்நேர தலைப்புகள் மற்றும் Windows இல் சாதனத்தில் AI அம்சங்கள் போன்ற AI பணிகளுக்காக உருவாக்கப்பட்ட ஒரு சிறிய, திறமையான செயலி.

முதல் கட்டுமானத்திற்கான நேர்மையான படம்:

  • இன்று AI அம்சங்களுக்கு "AI PC" உங்களுக்கு தேவையில்லை. தற்போதைய NPU கள் மிதமானவை. ஒரு சாதாரண CPU + GPU ஏற்கனவே அன்றாட AI கருவிகளை நன்றாக கையாள்கிறது.
  • கனமான AI வேலை (உள்ளூர் LLM கள், பட உருவாக்கம், பயிற்சி) NPU இல் அல்ல, GPU இல் இயங்குகிறது. இது உங்கள் இலக்கு என்றால், அதிக VRAM கொண்ட GPU வில் பட்ஜெட்டை செலவிடுங்கள்.
  • NPU கள் மிகவும் முக்கியமானவை மடிக்கணினிகளில் பேட்டரி ஆயுள் மற்றும் செயல்திறனுக்காக Windows AI அம்சங்களை தொடர்ந்து இயக்கும்போது. டெஸ்க்டாப்பில், அவை ஒரு நல்ல கூடுதல், முடிவு-செய்பவர் அல்ல.

எனவே: டெஸ்க்டாப் கட்டுமானத்தில் "AI PC" ஸ்டிக்கருக்கு பெரிய பிரீமியம் செலுத்த வேண்டாம். நீங்கள் உண்மையில் செய்யப்போவதற்கு – கேமிங், எடிட்டிங் அல்லது கோடிங் – CPU மற்றும் GPU ஐத் தேர்ந்தெடுங்கள், வழியில் சிறந்த AI செயல்திறனும் கிடைக்கும்.

7. மின்சாரம்: கஞ்சத்தனம் செய்ய வேண்டாம்

PSU ஐ புறக்கணிப்பது எளிது, ஆனால் கஞ்சத்தனம் செய்வதற்கு மிகவும் ஆபத்தான பகுதி இதுவே. விதிகள்:

  • அறியப்பட்ட பிராண்டிலிருந்து குறைந்தது 80 Plus Bronze மதிப்பீடு பெற்றதை வாங்குங்கள்.
  • ஹெட்ரூமுடன் அளவிடுங்கள் – ஒரு நல்ல கால்குலேட்டர் "~450W" என்று கூறுகிறது → 550–600W வாங்குங்கள்.
  • மற்றொரு கட்டுமானத்திலிருந்து சந்தேகத்திற்குரிய பழைய PSU ஐ ஒருபோதும் மீண்டும் பயன்படுத்த வேண்டாம்.

தோல்வியடையும் PSU கேஸில் உள்ள ஒவ்வொரு மற்ற பகுதியையும் சேதப்படுத்தலாம். கூடுதல் $20 மதிப்புடையது.

8. கேஸ், குளிரூட்டல் மற்றும் விசிறிகள்

கேஸ் பெரும்பாலும் அழகியல் + காற்றோட்டம். மெஷ் முன்பக்கம் மற்றும் குறைந்தது இரண்டு விசிறிகள் கொண்ட நன்கு மதிப்பாய்வு செய்யப்பட்ட எந்த நடுத்தர டவரும் நல்லது. பெரும்பாலான CPU களில் வேலை செய்யும் ஸ்டாக் கூலர் வருகிறது – வெப்பநிலை உங்களை தொந்தரவு செய்தால் பின்னர் மேம்படுத்துங்கள்.

உங்கள் கட்டுமான வரிசை (பட்ஜெட் எடுத்துக்காட்டு)

1. CPU            Ryzen 5 (gaming) / Core i5 (general)
2. Motherboard    B650 / B760 chipset, matches socket
3. RAM            16-32 GB DDR5, 2 sticks
4. Storage        1 TB NVMe SSD (boot) + optional HDD
5. GPU            NVIDIA RTX 4060 / AMD RX 7600 class
6. PSU            550-650W, 80+ Bronze or better
7. Case + fans    mesh front, a few 120mm fans
