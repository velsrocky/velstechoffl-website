Version control with Git for complete beginners

Git Tools Aug 24, 2026 · 7 min read

हर डेवलपर ने Git का इस्तेमाल किया होता है। यह वेबसाइट Git में संग्रहीत है। फिर भी यह अक्सर शून्य से शुरू किया जाता है। अच्छी खबर यह है कि Git एक बार आप इसका मानसिक मॉडल समझ लें तो बहुत ही सरल होता है – और आप 90% दैनिक काम के लिए केवल कुछ ही कमांड की जरूरत होती है।

Git किस समस्या का समाधान करता है? Git एक वितरित कोड नियंत्रण प्रणाली है जो एक परियोजना के इतिहास को ट्रैक करने और कई विकासकर्ताओं के बीच सहयोग को सुविधाजनक बनाने के लिए डिज़ाइन की गई है।

कागज़ की एक प्रति बनाएँगे – एक संस्करण से दूसरे संस्करण तक।report_final.doc, report_final_v2.doc, report_FINAL_actually.docअस्तित्व की हड़बड़ी

Git deta hai aapko.पूरे परियोजना का स्नैपशॉट हर बचाव के बादआपकी सेवा करने की क्षमताएं हैं:

  • 30 August 2023
  • परिवर्तनों की जांच करें और बदलाव के समय को निर्धारित करें।
  • कोड को काम करने के लिए सुरक्षित रखने के लिए विभिन्न प्रयोग करें
  • साथ में काम करने के लिए एक ऐसी प्रणाली का विकास किया गया है जो एक दूसरे को ओवरराइट न करे

मानसिक मॉडल: सेवा और सेवा-बिंदु

दो विचार जिन पर आपको ध्यान देना होगा

  • पूर्ण करना– एक सेव पॉइंट। आपके फाइल्स का एक स्नैपशॉट जैसे कि "लॉगिन बग को ठीक करें" के साथ।
  • संग्रहालय– एक ऐसा फोल्डर जो Git ट्रैक करता है। आपके सभी कॉमिट यहीं रहते हैं।

गिट की इतिहास एक ऐसी श्रृंखला है जो कमिट्स से बनी होती है।

पांच ऐसे आदेश जो सभी कामों को कवर करते हैं 1. प्रॉम्प्ट सेट करें – यह आदेश आपको अपनी आवश्यकताओं के अनुसार प्रॉम्प्ट सेट करने की अनुमति देता है। 2. मॉडल चुनें – यह आदेश आपको अपनी आवश्यकताओं के अनुसार मॉडल चुनने की अनुमति देता है। 3. डेटासेट लोड करें – यह आदेश आपको अपनी आवश्यकताओं के अनुसार डेटासेट लोड करने की अनुमति देता है। 4. इन्फरेंस चलाएं – यह आदेश आपको अपनी आवश्यकताओं के अनुसार इन्फरेंस चलाने की अनुमति देता है। 5. रिपोर्ट प्राप्त करें – यह आदेश आपको अपनी आवश्यकताओं के अनुसार रिपोर्ट प्राप्त करने की अनुमति देता है।

निर्मिति के लिए आवश्यक पूर्ण शुरुआती सामाग्री किट

git init          # start tracking this folder (do once)
git add .         # stage your changes (choose what to save)
git commit -m "message"   # create a save point
git status        # what's changed? (check constantly)
git log           # see the history of commits

addअबcommitविश्राम का ताल है। सबसे पहले आप क्या सेवा करना चाहते हैं, उसे चुन लें, फिर स्नैपशॉट लें। आप चलेंगेgit statusअतिरिक्त – यह एक सुरक्षा जांच है, कभी भी एक कार्य नहीं ।

विभाजन: समांतर ब्रह्मांड

Ashakhएक अलग विकास पंक्ति – प्रोजेक्ट की एक कॉपी जिस पर आप प्रयोग कर सकते हैं बिना मुख्य पंक्ति को प्रभावित किए।

git branch new-feature   # create a branch
git switch new-feature   # move to it
# ...work and commit here...
git switch main          # go back
git merge new-feature    # bring the work into main

केवल शुरुआती शख्सों के लिए शाखाएं वैकल्पिक लगती हैं – और वे हैं; शुरुआत में। लेकिन उन्हें जल्दी सीखने से आप वास्तविक टीमों के काम करने के तरीके से सहज हो जाते हैं। सोने की आदत:मुख्य branch में कभी भी कुछ जोखिम भरा करने से पहले फिक्सिंग branch में जाना चाहिए.

गिट: – क्लाउड में

गिटहबGit रिपॉजिटरी के लिए होस्टिंग सेवा है – जैसे कि ड्रॉपबॉक्स आपके कोड के लिए, साथ ही साथ सहयोग के उपकरण। उन्हें जोड़ने वाले कमांड हैं:

git clone URL        # copy a repo to your computer (start)
git push             # upload your commits
git pull             # download others' commits (or your own from another machine)

pushGitHub पर अपने सेवा को भेजता है।pullउन्हें नीचे ले जाता है। यही है कि इस वेबसाइट को निर्देशित करने का तरीका है – एक पुश को GitHub Pages को प्रकाशित करने के लिए ट्रिगर करता है।

गलतियों को ठीक करना (संतोषजनक हिस्सा)

वेर्जन नियंत्रण की सबसे अच्छी बात: लगभग कुछ भी स्थायी नहीं है।

git restore file         # discard uncommitted changes to a file
git reset --hard HEAD    # throw away uncommitted changes entirely
git revert <commit-id>    # undo a past commit safely
git log                  # find any commit-id you need

मुश्किल में फंस गया? ठीक करें। सब कुछ टूट गया? रीसेट करें। कुछ गलत किया है? वापस लें। गिट का पूरा काम ही पिछली स्थिति में वापस आने की अनुमति देना है।

एक अच्छी आदत से पहले की शुरुआत

  • छोटे-छोटे बदलाव करें और अक्सर कंप्यूटर पर सेव करें।हर विशेषता/सुधार के बाद एक सेव पॉइंट, एक स्पष्ट संदेश के साथ।
  • - Fixed bug in GPU – GPU में गड़बड़ी का सुधार किया गया है। - Improved CPU performance – CPU की प्रदर्शन में सुधार किया गया है। - Enhanced VRAM usage – VRAM के उपयोग में सुधार किया गया है। - Optimized RAM allocation – RAM के आवंटन को अनुकूलित किया गया है। - Added support for LLM – LLM के लिए समर्थन जोड़ा गया है। - Fixed GGUF issue – GGUF मुद्दे का समाधान किया गया है। - Improved Q4 performance – Q4 की प्रदर्शन में सुधार किया गया है। - Enhanced Q5 functionality – Q5 की कार्यक्षमता में सुधार किया गया है। - Fixed Q8 bug – Q8 में गड़बड़ी का समाधान किया गया है। - Optimized KV cache – KV cache को अनुकूलित किया गया है। - Improved RAG performance – RAG कीलॉगिन बग को ठीक करें – यह 'चीजें' से बेहतर है । भविष्य में आप खुद को धन्यवाद देंगे ।
  • काम को सुरक्षित करें – जोखिम उठाने से पहले।तो आप हमेशा पीछे जा सकते हैं।
  • गिट स्टेट्स चेक करेंजानने के लिए पहले, ताकि आप जान सकें कि क्या निकल रहा है।

एक आम पहली सेशन में एक व्यक्ति एक चैटबॉट से बात करता है, जैसे कि VelsChat या ChatGPT, और उनके प्रश्नों का उत्तर देता है। इस सेशन में व्यक्ति के प्रश्नों का उत्तर देने के लिए चैटबॉट को एक विशिष्ट विषय के बारे में जानकारी प्रदान करनी होती है। चैटबॉट के पास एक लंबी चर्चा करने की क्षमता होती है, जिसमें वह व्यक्ति के प्रश्नों का उत्तर देता है और उन्हें विशिष्ट जानकारी प्रदान करता है। इस सेशन में चैटबॉट का उद्देश्य व्यक्ति को उनके प्रश्नों का उत्तर देना और उन्हें विशिष्ट जानकारी प्रदान करना होता है। चैटबॉट का उपयोग विभिन्न

$ cd ~/myproject
$ git init                    # start tracking
$ git add .
$ git commit -m "Initial version of my app"
$ git branch main             # name the main branch (already set on most setups)
# ... edit some files ...
$ git status                  # "modified: index.html"
$ git add .
$ git commit -m "Add dark mode toggle"
$ git log --oneline           # 2 commits, nice and tidy

गिट ज्यादा बड़ा लगता है, लेकिन वास्तव में यह केवल:पॉइंट्स को सेव करना (commit), समान रेखाएँ बनाना (branch), और सिंक करना (push/pull)तीनों विचारों को स्वाद लें, और आप वेर्शन कंट्रोल का उपयोग करने में एक पेशेवर हैं। और सबसे अच्छी बात – एक बार शुरू करने के बाद, आप कभी भी इसके बिना काम नहीं करना चाहेंगे।
