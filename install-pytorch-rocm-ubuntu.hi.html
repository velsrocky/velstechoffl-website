Installing PyTorch with ROCm on Radeon GPUs

PyTorch ROCm Radeon Aug 25, 2026 · 5 min read

पायटॉर्च गहरे शिक्षण के लिए सबसे ज्यादा इस्तेमाल किया जाने वाला फ्रेमवर्क है, और AMD हार्डवेयर पर यहआरओसीएम (Rocm)ROCm को स्थापित करने के बाद, Radeon GPU पर PyTorch को काम करना बहुत आसान है।pip installदूर हो जाए।

मैंने इसे एक – विशिष्ट सिस्टम पर परीक्षण कियारेडिओन एक्स ६८००एम(gfx1031, RDNA2) के साथ ROCm 7.14 पर Ubuntu 26.04 – नीचे दिए गए निश्चित आदेश ही काम करते हैं। यही प्रक्रिया RDNA2/RDNA3 कार्डों के लिए भी लागू होती है; बस install आदेश में gfx टार्गेट को बदलें।

पूर्वापेक्षाएं - हिंदी में चैटबॉट डेवलपमेंट की जानकारी होना - प्रोग्रामिंग भाषा जैसे कि पायथन, जावा, सी++ में कुछ अनुभव होना - गणितीय और सांख्यिकीय अवधारणाओं का ज्ञान होना - कंप्यूटर विज्ञान और मशीन लर्निंग के क्षेत्र में रुचि होना - एक सॉफ्टवेयर डेवलपमेंट टूलचैट जैसे कि VelsChat का उपयोग करने की जानकारी होनी

  • ROCm का स्थापना और सत्यापित किया गया है– अगर आप अभी तक नहीं किया है तो हमारीरोकम को यूनिटी पर रेडियॉन जीपीयू के लिए स्थापित करना पहले, अपने सिस्टम को अद्यतन करें और आवश्यक पैकेजों को डाउनलोड करें: sudo apt update sudo apt install –y build-essential libnuma-dev libpciaccess-dev libdrm-dev libgbm-dev libegl1-mesa-dev libgles2-mesa-dev libwayland-dev libwayland-egl1-mesa-dev अब, ROCm को डाउनलोड और इंस्टॉल करें: wget https://api.github.com/repos/RadeonOpenCompute/ROCm/releases/latest –q –O – | grep 'browser_download_url' | cut –d '"' –f 4 | wget –O – –no-check-certificate tar –xvf rocm_*.tar.gz cd rocm_* sudo ./amdgpu-install –latest –no-dkms स्थापना प्रक्रिया के बाद, अपने सिस्टम को रीस्टार्ट करें: sudo reboot अब, अपने सिस्टम में लॉग इन करेंपहले मार्गदर्शन करें, और फिर पुष्टि करेंrocminfoअपना जीपीयू दिखाएँ।
  • पाइथन3.11, 3.12, 3.13, ya 3.14स्थापित किया गया।
  • आपके जीपीयूgfxarchitecture (e.g. gfx1031 RX 6800M के लिए)

पहला कदम – वर्चुअल एंट्रोप्रिनेमेंट बनाएँ

पायथन के लिए एक नया वर्चुअल वातावरण बनाएं ताकि यह कभी भी सिस्टम पैकेज या अन्य पायथन परियोजनाओं से टकराए।

python3.12 -m venv .venv

प्रयोग के लिए जिस पायथन संस्करण का उपयोग किया जा रहा है वह मेरे पास उपलब्ध है।python3.11, python3.13याpython3.14कार्य का पूरा होने पर एक फोल्डर.venvवर्तमान में मेरे निर्देशिका में।

दूसरा चरण – पर्यावरण को सक्रिय करें

एक्टिवेट करेंpythonaurpipवेंव की ओर इशारा करें:

source .venv/bin/activate

प्रोम्प्ट को दिखने पर ही यह काम करेगा(.venv)शुरुआत में

कदम 3 – PyTorch को ROCm साथ स्थापित करें

अमडी के व्हील रिपॉजिटरी से ROCm सक्षम PyTorch, torchvision, और torchaudio को स्थापित करें। अपने GPU का उपयोग करें।device-gfxराज्य – आरएक्स ६८००एम के लिएdevice-gfx1031: 

python -m pip install --index-url https://repo.amd.com/rocm/whl-multi-arch/ \
    "torch[device-gfx1031]==2.12.0+rocm7.14.0" \
    "torchvision[device-gfx1031]==0.27.0+rocm7.14.0" \
    "torchaudio==2.11.0+rocm7.14.0"

Kuchh notes:

  • Kya[device-gfx1031]ज्यादातर विशेषताएँ ROCm लाइब्रेरी को आपके विशिष्ट GPU आर्किटेक्चर के लिए अनुकूलित करती हैं –मैं एक पेशेवर हिंदी अनुवादक हूँ। मैं अंग्रेजी से हिंदी में अनुवाद करता हूँ। मैं तकनीकी शब्दों को अंग्रेजी में छोड़ देता हूँ: GPU, CPU, VRAM, RAM, LLM, GGUF, Q4, Q5, Q8, KV कैश, RAG, MoE, ROCm, Vulkan, CUDA, NPU, एसएसडी, एचडीडी, डीएनएस, एपीआई, ओल्लामा, लमा, लमा.cpp, टोकनाइज़र, टोकन, एम्बेडिंग, इन्फरेंस, क्वांटाइजेशन, मॉडल, डेटासेट, प्रम्प्ट। मैं ब्रांड नामों को छोड़ देता हूँ: वेल्सटेक, वेल्सचैट, चैटजीपीटी, क्लाउड, जेमिनी, क्वीन, अलीबाबा, नेवीडिया, एएमडी, इंटेल, एप.
  • अन्य कार्डों के लिए, लक्ष्य को बदलें: gfx1030 (RX 6800/6700 XT), gfx1100 (RX 7900 XTX), और इसी तरह[device-all]यदि आप सभी वास्तुकलाओं का समर्थन करना चाहते हैं एक ही बार में (बड़ा डाउनलोड)।
  • Kya+rocm7.14.0प्रकरण टैग को आपके इंस्टॉल किए गए ROCm संस्करण के साथ संगत होना चाहिए।
वेंव को सक्रिय रखें और यह सुनिश्चित करें कि आप आवश्यक प्राधिकरण पास कर रहे हैं जब pip को निर्भरता को हल करने के लिए समस्या हो।--index-url https://repo.amd.com/rocm/whl-multi-arch/उस रिपॉजिटरी में AMD ROCm के बिल्ड्स को प्रकाशित करता है।

चरण 4 – GPU की जांच करें

अमडी जीपीयू की पुष्टि करने के लिए इस एकल लाइनर को चलाएं: ```python import torch print(torch.cuda.is_available()) ``` या अमडी जीपीयू की पुष्टि करने के लिए इस एकल लाइनर को चलाएं: ```python import torch print(torch.cuda.get_device_name(0)) ```

python -c "import torch; print(torch.cuda.is_available())"

प्रिंट करता हैTrueयदि PyTorch और ROCm सही ढंग से स्थापित हैं और आपका AMD GPU पहचाना जाता है (हाँ, यह सच है)cudaAPI – पाइथोन के – PyTorch में ROCm के लिए वही इंटरफेस रखा जाता है ताकि कोड पोर्टेबल हो।

आपको डिवाइस का नाम आगे जाँच करना चाहिए।

python -c "import torch; print(torch.cuda.get_device_name(0))"

RX 6800M पर यह कुछ इस तरह का रिपोर्ट करता है –AMD Radeon RX 6800M.

अगला क्या है?

पायथन के साथ ROCm पर चलने पर आप: - पायथन के साथ विभिन्न प्रकार के कार्यों को प्रदर्शित कर सकते हैं - पायथन के साथ विभिन्न प्रकार के GPU-आधारित कार्यों को प्रदर्शित कर सकते हैं - पायथन के साथ विभिन्न प्रकार के कंप्यूटर विज़ुअलाइज़ेशन कार्यों को प्रदर्शित कर सकते हैं - पायथन के साथ विभिन्न प्रकार के मशीन लर्निंग कार्यों को प्रदर्शित कर सकते हैं

  • गणना के लिए पूर्ण GPU गति प्रदान करने के लिए मॉडल को प्रशिक्षित करें और निर्णय लेने के लिए इन्फरेंस करें
  • लोकल पर LLMs चलाएं – हगिंग फेस ट्रांसफॉर्मर्स, टेक्स्ट जनरेशन वेबयूआई, और समान उपकरण बॉक्स आउट ऑफ द बॉक्स काम करते हैं
  • टॉर्चविजन का उपयोग करके चित्र मॉडल और टॉर्चऑडियो का उपयोग करके ऑडियो पाइपलाइनें

अगर आपको और जानकारी की आवश्यकता है तो आधिकारिक गाइड में अधिक विवरण है।अमडी आरओसीएम – एआई इकोसिस्टम दस्तावेज़ में पायथन लोड करें: पायथन 3.7 या उच्चतर का उपयोग करें। सुनिश्चित करें कि आपके पास AMD ROCm सॉफ्टवेयर स्थापित है, जिसमें AMD GPU ड्राइवर भी शामिल है। AMD ROCm सॉफ्टवेयर डाउनलोड करें और इसे स्थापित करें। AMD ROCm सॉफ्टवेयर स्थापित करने के बाद, आपको AMD GPU ड्राइवर को भी स्थापित करना होगा। AMD GPU ड्राइवर डाउनलोड करें और इसे स्थापित करें। AMD GPU ड्राइवर स्थापित करने के बाद, आपको ROCm-clang और ROCm-cmake को स्थापित करना होगा। ROCm-clang और ROCm-cmake स्थापित करने के लिए निम्नलिखित कमांड का उपयोग करें.
