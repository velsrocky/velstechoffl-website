Radeon GPU களுக்காக Ubuntu இல் ROCm நிறுவுதல்

ROCm Radeon GPU Aug 25, 2026 · 6 நிமிட வாசிப்பு

AMD இன் ROCm (Radeon Open Compute) தளம், PyTorch, TensorFlow, LLM அனுமானம் போன்ற GPU-முடுக்கப்பட்ட பணிச்சுமைகளை AMD GPU களில் இயக்க உங்களை அனுமதிக்கிறது. ஆதரிக்கப்படும் Radeon கார்டு இருந்தால் – RDNA2 (RX 6000 தொடர் / gfx1030) அல்லது RDNA3 (RX 7000 தொடர் / gfx1100) – இந்த வழிகாட்டி Ubuntu 26.04 LTS இல் ROCm 7.14 ஐ நிறுவுவதன் மூலம் உங்களை அழைத்துச் செல்கிறது.

நான் இதை Radeon RX 6800M (gfx1031, RDNA2) இல் சோதித்தேன், கீழே உள்ள அனைத்தும் உண்மையில் வேலை செய்தவை. இதே படிகள் பெரும்பாலான RDNA அடிப்படையிலான கார்டுகளுக்கும் பொருந்தும்.

முன்நிபந்தனைகள்

  • ஆதரிக்கப்படும் பட்டியலில் இருந்து ஒரு AMD Radeon GPU
  • Ubuntu 26.04 LTS (Resolute Raccoon) நிறுவப்பட்டிருக்க வேண்டும்
  • ஒரு இணைய இணைப்பு
  • sudo சலுகைகள் கொண்ட ஒரு பயனர் கணக்கு

படி 1 – amdgpu-install ஸ்கிரிப்ட்டை நிறுவவும்

ROCm, GPU டிரைவர், ROCm ரன்டைம், கிராபிக்ஸ் கூறுகளை ஒன்றாகக் கையாள amdgpu-install ஸ்கிரிப்ட்டைப் பயன்படுத்துகிறது. அதை AMD இன் களஞ்சியத்திலிருந்து பதிவிறக்கி நிறுவவும்: 

sudo apt update
wget https://repo.radeon.com/amdgpu-install/31.40.1/ubuntu/resolute/amdgpu-install_31.40.1.314001-1_all.deb
sudo apt install ./amdgpu-install_31.40.1.314001-1_all.deb

நீங்கள் வேறு Ubuntu பதிப்பில் இருந்தால் resolute ஐ noble (24.04) அல்லது jammy (22.04) உடன் மாற்றவும்.

படி 2 – ROCm மற்றும் GPU டிரைவரை நிறுவவும்

பொருத்தமான பயன்பாட்டு வழக்கு (use case) மற்றும் GPU இலக்குடன் amdgpu-install ஐ இயக்கவும். 

sudo amdgpu-install --usecase=rocm,graphics --gfxversion=gfx1031

முக்கியமானது: auto க்கு பதிலாக உங்கள் GPU இன் குறிப்பிட்ட gfx இலக்கைப் பயன்படுத்தவும். தானியங்கி கண்டறிதல் சில நேரங்களில் சரியான கட்டமைப்பைத் தவறவிடலாம், எனவே அதை வெளிப்படையாகக் குறிப்பிடுவது சுத்தமான நிறுவலை அளிக்கிறது. உங்கள் GPU இன் gfx பதிப்பைக் கண்டறியவும்:

  • RDNA2 (RX 6000 தொடர்): gfx1030, gfx1031, gfx1032
  • RDNA3 (RX 7000 தொடர்): gfx1100, gfx1101, gfx1102
  • RDNA3.5 (Ryzen AI 300): gfx1150, gfx1151

உறுதியாக தெரியவில்லையா? நிறுவிய பிறகு rocminfo இயக்கவும் (அல்லது உங்கள் கார்டின் கட்டமைப்பை AMD இன் தளத்தில் பார்க்கவும்).

சாதனக் குடும்பக் குறிப்பு: இன்ஸ்டாலர் உங்களை ஒரு சாதனக் குடும்பத்தைத் தேர்ந்தெடுக்கக் கேட்கும்போது, உங்களுக்கு இரண்டு விருப்பங்கள் உள்ளன:
  • All – ஒவ்வொரு AMD GPU கட்டமைப்பிற்கும் ரன்டைம் ஆதரவை நிறுவுகிறது. குறுக்கு-தளத்தில் டெவலப் செய்கிறீர்களோ அல்லது பல கார்டுகளில் சோதிக்கிறீர்களோ என்றால் நல்லது.
  • AMD Radeon – நுகர்வோர் Radeon GPU களை மட்டும் இலக்காகக் கொள்கிறது. ஒரு ஒற்றை Radeon கார்டுக்கு இதுவே மெலிந்த, அதிக கவனம் செலுத்தும் தேர்வு.
நீங்கள் உங்கள் சொந்த இயந்திரத்தை மட்டும் பயன்படுத்தினால், AMD Radeon ஐத் தேர்ந்தெடுக்கவும். பிறகு Instinct அல்லது மற்ற கட்டமைப்புகளில் இயங்கக்கூடிய ஒன்றை உருவாக்கினால், All ஐத் தேர்ந்தெடுக்கவும்.

படி 3 – கூடுதல் நூலகங்களை நிறுவவும்

சில ROCm கருவிகள் சரியாக இயங்க libatomic மற்றும் libquadmath நூலகங்கள் தேவை. பிறகு ஒரு தெளிவற்ற பிழையைச் சந்திக்காமல் இருக்க அவற்றை இப்போதே நிறுவவும்: 

sudo apt install libatomic1 libquadmath0

படி 4 – உங்கள் பயனரை render மற்றும் video குழுக்களில் சேர்க்கவும்

GPU அணுகல் Linux குழுக்கள் மூலம் கட்டுப்படுத்தப்படுகிறது. sudo இல்லாமல் AMD GPU ஐப் பயன்படுத்த உங்கள் பயனர் render மற்றும் video குழுக்களில் இருக்க வேண்டும்: 

sudo usermod -a -G render,video $LOGNAME

குழு மாற்றம் பலனளிக்க வெளியேறி மீண்டும் உள்நுழையவும் (அல்லது மறுதொடக்கம் செய்யவும்).

படி 5 – மறுதொடக்கம்

கெர்னல் மாட்யூல் (amdgpu) மற்றும் ROCk டிரைவர் ஏற்றப்படுவதை மறுதொடக்கம் உறுதி செய்கிறது: 

sudo reboot

படி 6 – நிறுவலைச் சரிபார்க்கவும்

மறுதொடக்கத்திற்குப் பிறகு, உங்கள் GPU கண்டறியப்படுவதை உறுதிப்படுத்த rocminfo இயக்கவும்: 

rocminfo

உங்கள் GPU அதன் பெயர், gfx கட்டமைப்பு, கம்ப்யூட் யூனிட்களுடன் பட்டியலிடப்பட்டிருப்பதைக் காண வேண்டும். ஆரோக்கியமான வெளியீடு இப்படி இருக்கும்: 

*******
Agent 2
*******
  Name:                    gfx1031
  Marketing Name:          AMD Radeon RX 6800M
  Compute Unit:            40
  Device Type:             GPU
  ...

கெர்னல் டிரைவர் ஏற்றப்பட்டுள்ளதையும் சரிபார்க்கலாம்: 

ls /dev/kfd   # should exist
ls /dev/dri/  # should show renderD* nodes

அடுத்து என்ன?

ROCm நிறுவப்பட்டவுடன், நீங்கள் இப்போது:

  • ROCm ஆதரவுடன் PyTorch நிறுவலாம் – pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm7.1
  • LLM களை உள்ளூரில் இயக்கலாம் – Ollama, LM Studio, மற்றும் text-generation-webui போன்ற கருவிகள் அனைத்தும் ROCm ஐ ஆயத்தமாக ஆதரிக்கின்றன.
  • GPU புரோகிராமிங்கிற்கு HIP பயன்படுத்தலாம் – AMD இன் CUDA-இணக்கமான கட்டமைப்பு.

இன்ஸ்டாலர் உங்கள் GPU வைக் கண்டறியவில்லை என்றால், --gfxversion கொடியை இருமுறை சரிபார்த்து All சாதனக் குடும்ப விருப்பத்தை முயற்சிக்கவும். சிக்கல்கள் ஏற்பட்டால், AMD இன் அதிகாரப்பூர்வ ROCm நிறுவல் வழிகாட்டியில் முழு விவரங்கள் உள்ளன.
