Linux कमांड चीट शीट

मुफ़्त डाउनलोड · प्रिंट करने योग्य · वे कमांड जो आप वास्तव में उपयोग करेंगे

नीचे दिए गए कमांड रोज़मर्रा के 95% Linux उपयोग को कवर करते हैं – नेविगेशन, फ़ाइलें, अनुमतियाँ, प्रोसेसेस, नेटवर्किंग और पैकेज प्रबंधन। इस पेज को बुकमार्क करें, या इसे प्रिंट करें (Ctrl+P / Cmd+P) और एक कॉपी अपनी मेज़ पर रखें।

🖥️ नेविगेशन और फ़ाइलें

pwdवर्तमान डायरेक्टरी प्रिंट करें
lsफ़ाइलें सूचीबद्ध करें
ls -laविवरण और छिपी हुई फ़ाइलों के साथ सभी फ़ाइलें सूचीबद्ध करें
cd dirडायरेक्टरी में बदलें
cd ~होम डायरेक्टरी पर जाएँ
cd ..एक स्तर ऊपर जाएँ
mkdir dirडायरेक्टरी बनाएँ
rm fileफ़ाइल हटाएँ (सावधान – वापस नहीं आती)
rm -r dirडायरेक्टरी को पुनरावर्ती रूप से हटाएँ
cp a bकॉपी करें a → b
mv a bले जाएँ / नाम बदलें a → b
touch fileखाली फ़ाइल बनाएँ
cat fileफ़ाइल की सामग्री प्रिंट करें
less fileफ़ाइल देखें (स्क्रॉल करें, बाहर निकलने के लिए q)
head / tail fileपहली / आखिरी 10 लाइनें
tail -f fileफ़ाइल को बढ़ते हुए देखें (लॉग)
grep pattern fileपैटर्न से मेल खाती लाइनें खोजें
find . -name "*.txt"नाम से फ़ाइलें खोजें

🔐 अनुमतियाँ और स्वामित्व

chmod 755 fileअनुमतियाँ सेट करें (rwxr-xr-x)
chmod +x fileनिष्पादन योग्य बनाएँ
chown user fileस्वामी बदलें
chown -R user dirस्वामी को पुनरावर्ती रूप से बदलें
ls -lअनुमतियाँ दिखाएँ
sudo commandएडमिनिस्ट्रेटर के रूप में चलाएँ

📦 पैकेज प्रबंधन (apt – Debian/Ubuntu)

sudo apt updateपैकेज सूची ताज़ा करें
sudo apt upgradeस्थापित पैकेज अपग्रेड करें
sudo apt install pkgएक पैकेज स्थापित करें
sudo apt remove pkgएक पैकेज हटाएँ
apt search termउपलब्ध पैकेज खोजें
dpkg -lस्थापित पैकेज सूचीबद्ध करें

⚙️ प्रोसेसेस और सिस्टम

ps auxचल रहे प्रोसेसेस सूचीबद्ध करें
top / htopलाइव सिस्टम मॉनिटर
kill PIDएक प्रोसेस समाप्त करें
kill -9 PIDएक प्रोसेस जबरन समाप्त करें
systemctl status svcसर्विस की स्थिति
systemctl start/stop svcसर्विस शुरू / बंद करें
systemctl enable svcबूट पर सर्विस शुरू करें
df -hडिस्क उपयोग
du -sh dirडायरेक्टरी का आकार
free -hमेमोरी उपयोग
uname -aकेर्नल जानकारी

🌐 नेटवर्किंग

ping hostकनेक्टिविटी जाँचें
ip addrIP पते दिखाएँ
curl URLएक URL लाएँ
wget URLएक फ़ाइल डाउनलोड करें
ssh user@hostSSH के माध्यम से कनेक्ट करें
scp f user@h:/pathSSH पर फ़ाइल कॉपी करें
netstat -tulpnखुले पोर्ट दिखाएँ
dig domainDNS लुकअप

🧰 उपयोगी शॉर्टकट और ट्रिक्स

Tabऑटो-कंप्लीट
↑ / ↓कमांड इतिहास
Ctrl + Cवर्तमान कमांड रद्द करें
Ctrl + Dशेल बाहर निकलें / EOF
Ctrl + Rइतिहास खोजें
command | grep xआउटपुट को खोज में पाइप करें
command > fileआउटपुट को फ़ाइल में सहेजें
!!पिछला कमांड दोहराएँ
man commandमैनुअल / सहायता
