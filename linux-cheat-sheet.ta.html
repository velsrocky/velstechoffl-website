Linux கட்டளை குயிக் ரெஃபரன்ஸ்

இலவச பதிவிறக்கம் · அச்சிடத்தக்கது · நீங்கள் உண்மையில் பயன்படுத்தும் கட்டளைகள்

கீழே உள்ள கட்டளைகள் தினசரி Linux பயன்பாட்டின் 95% உள்ளடக்குகின்றன – நேவிகேஷன், கோப்புகள், அனுமதிகள், செயல்முறைகள், நெட்வொர்க்கிங், மற்றும் பேக்கேஜ் மேலாண்மை. இந்தப் பக்கத்தை புக்மார்க் செய்யுங்கள், அல்லது உங்கள் மேசையில் ஒரு நகலை வைத்திருக்க அச்சிடுங்கள் (Ctrl+P / Cmd+P).

🖥️ நேவிகேஷன் & கோப்புகள்

pwdதற்போதைய கோப்பகத்தை அச்சிடு
lsகோப்புகளை பட்டியலிடு
ls -laஅனைத்து கோப்புகளையும் விவரங்கள் & மறைக்கப்பட்ட கோப்புகளுடன் பட்டியலிடு
cd dirகோப்பகத்திற்கு மாறு
cd ~ஹோம் கோப்பகத்திற்கு செல்
cd ..ஒரு நிலை மேலே செல்
mkdir dirகோப்பகத்தை உருவாக்கு
rm fileகோப்பை நீக்கு (கவனம் – மீள முடியாது)
rm -r dirகோப்பகத்தை மீண்டும் மீண்டும் நீக்கு
cp a ba → b நகலெடு
mv a ba → b நகர்த்து / மறுபெயரிடு
touch fileகாலி கோப்பை உருவாக்கு
cat fileகோப்பு உள்ளடக்கத்தை அச்சிடு
less fileகோப்பை பார்க்க (ஸ்க்ரோல், வெளியேற q)
head / tail fileமுதல் / கடைசி 10 வரிகள்
tail -f fileகோப்பு வளர்வதை பார்க்க (லாக்ஸ்)
grep pattern fileவடிவத்துடன் பொருந்தும் வரிகளை தேடு
find . -name "*.txt"கோப்புகளை பெயரால் கண்டறி

🔐 அனுமதிகள் & உரிமை

chmod 755 fileஅனுமதிகளை அமைக்க (rwxr-xr-x)
chmod +x fileஇயங்கக்கூடியதாக மாற்று
chown user fileஉரிமையாளரை மாற்று
chown -R user dirஉரிமையாளரை மீண்டும் மீண்டும் மாற்று
ls -lஅனுமதிகளை காட்டு
sudo commandநிர்வாகியாக இயக்கு

📦 பேக்கேஜ் மேலாண்மை (apt – Debian/Ubuntu)

sudo apt updateபேக்கேஜ் பட்டியலை புதுப்பி
sudo apt upgradeநிறுவப்பட்ட பேக்கேஜ்களை மேம்படுத்து
sudo apt install pkgஒரு பேக்கேஜை நிறுவு
sudo apt remove pkgஒரு பேக்கேஜை நீக்கு
apt search termகிடைக்கும் பேக்கேஜ்களை தேடு
dpkg -lநிறுவப்பட்ட பேக்கேஜ்களை பட்டியலிடு

⚙️ செயல்முறைகள் & அமைப்பு

ps auxஇயங்கும் செயல்முறைகளை பட்டியலிடு
top / htopநேரடி அமைப்பு மானிட்டர்
kill PIDஒரு செயல்முறையை முடி
kill -9 PIDஒரு செயல்முறையை வலுக்கட்டாயமாக முடி
systemctl status svcசேவை நிலை
systemctl start/stop svcஒரு சேவையை தொடங்கு / நிறுத்து
systemctl enable svcதுவக்கத்தில் சேவையை தொடங்கு
df -hவட்டு பயன்பாடு
du -sh dirகோப்பக அளவு
free -hநினைவக பயன்பாடு
uname -aகேர்னல் தகவல்

🌐 நெட்வொர்க்கிங்

ping hostஇணைப்பை சரிபார்
ip addrIP முகவரிகளை காட்டு
curl URLஒரு URL-ஐ பெறு
wget URLஒரு கோப்பை பதிவிறக்கு
ssh user@hostSSH வழியாக இணை
scp f user@h:/pathSSH மீது கோப்பை நகலெடு
netstat -tulpnதிறந்த போர்ட்களை காட்டு
dig domainDNS lookup

🧰 பயனுள்ள குறுக்குவழிகள் & தந்திரங்கள்

Tabதானாக நிறைவு
↑ / ↓கட்டளை வரலாறு
Ctrl + Cதற்போதைய கட்டளையை ரத்து
Ctrl + Dஷெல் / EOF-லிருந்து வெளியேறு
Ctrl + Rவரலாற்றை தேடு
command | grep xவெளியீட்டை தேடலுக்கு அனுப்பு
command > fileவெளியீட்டை கோப்பில் சேமி
!!கடைசி கட்டளையை மீண்டும் செய்
man commandகையேடு / உதவி
