llama.cpp guide: run GGUF models locally

llama.cpp GGUF Local AI Aug 30, 2026 · 7 min read

ओल्लामा, एलएम स्टूडियो, और अधिकांश अन्य स्थानीय एआई टूल्स को चालू करने वाला ल्लामा .cpp इंजन है। यह एक सी++ लाइब्रेरी है जो जीजूएफ मॉडल्स को लोड करता है और आपके CPU, GPU, या दोनों पर चलाता है, जिसमें नेविटिया क्यूडीए, एमडी आरओसीएम, और वुल्केन का समर्थन शामिल है।

यह गाइड मूलभूत बातों को कवर करती है: कैसे इसे स्थापित करें, कैसे एक मॉडल चलाएं, कैसे अपना GPU सक्षम करें, और कैसे बेंचमार्क आउटपुट पढ़ें। गाइड के अंत में आप सटीक रूप से जान जाएंगे कि1713 ms / 373 tok = 4.60 ms/tok = 217.6 tok/sक्या ये पर्याप्त तेज़ हैं (और क्या यह तेज़ होना पर्याप्त है)।

स्थापना 1. विंडोज़ 10 या उच्चतर पर चलने वाले कंप्यूटर पर वेल्सटेक वेल्सचैट को डाउनलोड और इंस्टॉल करें। 2. विंडोज़ 10 या उच्चतर पर चलने वाले कंप्यूटर पर क्लाउड और चैटजीपीटी को डाउनलोड और इंस्टॉल करें। 3. क्लाउड और चैटजीपीटी को एक साथ जोड़ने के लिए अपने क्लाउड खाते में जाएं और चैटजीपीटी को एक्सेस करें। 4. अपने वेल्सचैट ऐप में जाएं और क्लाउड और चैटजीपीटी को जोड़ने के लिए निर्देशों का पालन करें। 5. वेल्सचैट को क्लाउड और चैटजीपीटी से जोड़ने के बाद, आप चैटजीपीटी से जुड़े

लल्ला .cpp प्राप्त करने का सबसे आसान तरीका स्रोत से बनाना है। इसके लिए आपको एक C++ कंपाइलर की आवश्यकता है।cmake: 

git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp
mkdir build && cd build
cmake .. -DLLAMA_METAL=OFF
make -j$(nproc)

GPU (GPU) को गति प्रदान करने के लिए सही फ्लैग जोड़ें: -cuda-gpu-arch=sm_80

  • नेवीडिया CUDA cmake .. -DLLAMA_CUDA=ON
  • एएमडी आरओसीएम: cmake .. -DLLAMA_HIPBLAS=ON
  • वुल्कन cmake .. -DLLAMA_VULKAN=ON
  • एप्पल मेटल cmake .. -DLLAMA_METAL=ON

यदि आप Ubuntu पर AMD कार्ड के साथ हैंROCM स्थापना गाइड ROCM (Radeon Open Compute) को स्थापित करने के लिए निम्नलिखित चरणों का पालन करें: **पहला चरण: प्राथमिक आवश्यकताएँ** - एक AMD Radeon GPU होना आवश्यक है। - एक Linux या Ubuntu परिचालन प्रणाली होनी आवश्यक है। - प्रारंभिक स्थापना के लिए 1 GB से अधिक स्थान आवश्यक है। **दूसरा चरण: पैकेजों को अपडेट करें** - अपने Linux या Ubuntu परिचालन प्रणाली को अपडेट करें। - कमांड प्रॉम्प्ट में निम्नलिखित कमांड चलाएँ: `sudo apt update` और `sudo apt upgrade` **तीसरा चरण: ROCm को डाउनलोड और स्थापित करें** - AMD की आधिकारिक वेबसाइट से ROCm को डाउनलोड करें। - डाउनलोड किए गए फ़ाइल को अपने Linuxप्रारंभिक आवश्यकताओं का पूर्वावलोकन करता है।

मॉडल चलाना

डाउनलोड करें एक GGUF फ़ाइलGGUF (GPT-3.5 GYM Unified Framework) – एक ऐसी तकनीकी प्रणाली है जो चैटबॉट्स को विभिन्न प्रकार की भाषा प्रक्रियाओं में सुधार करने में मदद करती है। यह प्रणाली विभिन्न भाषा मॉडलों को एकीकृत करती है और उन्हें एक ही प्लेटफ़ॉर्म पर चलने की अनुमति देती है, जिससे चैटबॉट्स को अधिक प्रभावी ढंग से काम करने में मदद मिलती है।जिसके लिए (एक से चुनें) फिर:

./build/bin/llama-cli -m path/to/model.q4_k_m.gguf -p "Hello, who are you?" -n 256

यह मॉडल को लोड करता है, प्रॉम्प्ट को चलाता है, और 256 टोकन पैदा करता है। निकाले गए आउटपुट में समय संबंधी जानकारी होती है जो आपको बताती है कि यह कितनी तेजी से चला है।

GPU (GPU) में तेजी

प्रारंभिक llama.cpp कार्यान्वयन GPU पर लेयर्स ऑफलोड करने के लिए डिफ़ॉल्ट रूप से CPU पर चलता है। GPU पर लेयर्स ऑफलोड करने के लिए अपने GPU का उपयोग करने के लिए निम्नलिखित का उपयोग करें: 1. GPU को CUDA या ROCm से जोड़ें। 2. GPU को Vulkan API से जोड़ें। 3. GPU को NVIDIA, AMD, या Intel के GPU ड्राइवर से जोड़ें। 4. GPU को अपने सिस्टम में जोड़ें, जैसे कि NVIDIA GeForce, AMD Radeon, या Intel Iris GPU। 5. GPU को अपने सिस्टम के RAM से जोड़ें। 6. GPU को अपने सिस्टम के VRAM से जोड़ें। 7. GPU को अपने सिस्टम के GPU कैश से जोड़ें, जैसे कि KV cache। 8. GPU को अपने सिस्टम के LLM मॉडल-nglGPU layer की संख्या

./build/bin/llama-cli -m model.gguf -p "Hello" -n 256 -ngl 999

GPU क्लॉक स्पीड को GPU क्लॉक स्पीड के साथ गुणा करें: 2. ग्राफिक्स रैम (VRAM)क्या मैं अनुमान लगा सकता हूँ?
