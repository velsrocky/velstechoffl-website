ஒரு டொமைனை அமைத்து அதை எங்கும் சுட்டிக்காட்டுதல்

Networking DNS சுய-ஹோஸ்டிங் Aug 24, 2026 · 7 நிமிட வாசிப்பு 🤖 AI-assisted

ஒரு டொமைன் என்பது நீங்கள் சொந்தமாக்கக்கூடிய மிக சக்திவாய்ந்த இணைய ரியல் எஸ்டேட் துண்டு ஆகும். இது நீங்கள் கட்டுப்படுத்தும் ஒரு நிரந்தர முகவரி – மேலும் அதை ஒரு வலைத்தளம், ஒரு சர்வர் அல்லது ஒரு வீட்டு இயந்திரத்தில் சுட்டிக்காட்ட சில DNS பதிவுகள் மட்டுமே தேவை. இந்த தளம் இப்படித்தான் இயங்குகிறது.

டொமைனை வாங்குதல்

நீங்கள் ஒரு பதிவாளரிடமிருந்து ஒரு டொமைனை வாங்குகிறீர்கள் – ஒரு மேல்-நிலை டொமைனில் (TLD) பெயர்களை விற்க அங்கீகரிக்கப்பட்ட ஒரு நிறுவனம். புத்திசாலித்தனமாக தேர்வு செய்யுங்கள்:

  • Cloudflare Registrar – செலவு விலையில் விற்கிறது, எந்த மார்க்அப்பும் இல்லை, இலவச மேலாண்மை. சிறந்த மதிப்பு.
  • Namecheap, Porkbun – மலிவானது மற்றும் ஆரம்பநிலையாளர்களுக்கு நட்பானது.
  • GoDaddy – வேலை செய்கிறது, ஆனால் செக் அவுட்டில் அப்செல்களை எதிர்பார்க்கவும்.

TLD தேர்வு மக்கள் நினைப்பதை விட முக்கியமானது:

  • .com – கிளாசிக், மிகவும் நம்பத்தகுந்தது, ஆனால் பெரும்பாலும் எடுக்கப்பட்டது.
  • .net, .org, .dev, .io – திடமான மாற்றுகள்.
  • ஆடம்பரமான TLDகள் (.xyz, .club) – மலிவானவை, ஆனால் குறைவான தீவிரமானவை போல் தெரிகின்றன.

புதுப்பிப்பு விலையில் கவனமாக இருங்கள்: பல டொமைன்கள் முதல் ஆண்டு மலிவானவை மற்றும் பின்னர் திடீரென அதிகரிக்கின்றன. Cloudflare புதுப்பிப்புகளையும் அதே விலையில் வைத்து இதைத் தவிர்க்கிறது.

DNS பதிவுகளைப் புரிந்துகொள்ளுதல்

ஒரு டொமைன் மட்டும் எதுவும் செய்யாது. நீங்கள் DNS பதிவுகளை பயன்படுத்தி அது எங்கு சுட்டிக்காட்டுகிறது என்பதை உலகுக்குச் சொல்கிறீர்கள். நீங்கள் உண்மையில் பயன்படுத்தும் பதிவுகள்: 

Type     Example                         Purpose
──────────────────────────────────────────────────────────
A        185.199.108.153                 IPv4 address
AAAA     2606:4700:4700::1111            IPv6 address
CNAME    velsrocky.github.io             alias to another name
MX       mail.yourdomain.com             email delivery
TXT      "v=spf1 ..."                    verification / security

A பதிவுகள் ஒரு டொமைனை ஒரு IP-க்கு மேப் செய்கின்றன. CNAME ஒரு டொமைனை மற்றொரு டொமைனுக்கு மேப் செய்கிறது – உங்களுக்கு ஒரு பெயரைக் கொடுக்கும் சேவைகளுக்கு பயனுள்ளது (உதாரணமாக username.github.io).

சூழ்நிலை A: GitHub Pages (இந்த தளம்)

ஒரு இலவச GitHub Pages தளத்துடன் ஒரு டொமைனை இணைக்க: 

A        @      ->  185.199.108.153
A        @      ->  185.199.109.153
A        @      ->  185.199.110.153
A        @      ->  185.199.111.153
CNAME    www    ->  username.github.io
  1. உங்கள் DNS வழங்குநரிடம் அந்த பதிவுகளைச் சேர்க்கவும்.
  2. GitHub ரெப்போவில்: Settings → Pages → Custom domain → உங்கள் டொமைனை உள்ளிடவும்.
  3. GitHub பதிவுகளை சரிபார்த்து தானாகவே ஒரு இலவச HTTPS சான்றிதழை வழங்குகிறது.

சூழ்நிலை B: ஒரு VPS அல்லது டெடிகேட்டட் சர்வர்

நீங்கள் ஒரு சர்வரை வாடகைக்கு எடுத்தால் (Linode, DigitalOcean, Hetzner, ஒரு VPS), உங்கள் டொமைனை அதன் IP-யில் சுட்டிக்காட்டவும்: 

A        @   ->  203.0.113.10      (your server's IP)
CNAME    www ->  @                    (www follows the root)

பின்னர் உங்கள் வெப் சர்வரை (Nginx, Apache, Caddy) உங்கள் தளத்தை வழங்க உள்ளமைக்கவும் மற்றும் இலவச Let's Encrypt சான்றிதழுடன் HTTPS-ஐ அமைக்கவும்.

சூழ்நிலை C: ஒரு வீட்டு சர்வர்

வீட்டு நெட்வொர்க்கிங் ஒரு அடுக்கை சேர்க்கிறது – உங்கள் வீட்டில் ஒரு பொது IP உள்ளது, NAT வழியாக ஒவ்வொரு சாதனத்தாலும் பகிரப்படுகிறது. உங்களுக்குத் தேவை:

  1. போர்ட் ஃபார்வர்டிங் – வெப் ட்ராஃபிக்கை (போர்ட் 443) உங்கள் சர்வரின் தனிப்பட்ட IP-க்கு அனுப்ப உங்கள் ரூட்டருக்குச் சொல்லுங்கள்.
  2. ஒரு நிலையான பொது IP – வீட்டு இணைப்புகள் அடிக்கடி IP-களை மாற்றுகின்றன. உங்கள் IP மாறும்போது DNS பதிவைப் புதுப்பிக்கும் ஒரு DDNS சேவையைப் பயன்படுத்தவும்.
  3. HTTPS – Let's Encrypt DNS பதிவுகள் மூலம் உரிமையை சரிபார்க்க முடியும், எனவே இது வீட்டு IP-களிலும் வேலை செய்கிறது.
பாதுகாப்பு குறிப்பு: ஒரு வீட்டு சர்வரை இணையத்தில் வெளிப்படுத்துவது உண்மையானது. எல்லாவற்றையும் புதுப்பித்த நிலையில் வைக்கவும், SSH கீகளைப் பயன்படுத்தவும், மேலும் உங்கள் உண்மையான IP-யை மறைக்கும் கூடுதல் கேடயமாக Cloudflare-ன் இலவச ப்ராக்ஸியைக் கருத்தில் கொள்ளவும்.

மின்னஞ்சல் மற்றும் சரிபார்ப்பு பதிவுகள்

you@yourdomain.com வேண்டுமா? அதற்கு உங்கள் மின்னஞ்சல் வழங்குநரை (Gmail/Workspace, Zoho, அல்லது ஒரு தனிப்பயன் மெயில் சர்வர்) சுட்டிக்காட்டும் MX பதிவுகள் தேவை. வழங்குநர்கள் உங்கள் டொமைன் அதன் மெயிலை சொந்தமாகக் கொண்டுள்ளது என்பதை நிரூபிக்க TXT பதிவுகளையும் (SPF, DKIM) கேட்கிறார்கள்.

பொதுவான சிக்கல்கள்

  • பரப்புதல் நேரம் எடுக்கும் – DNS மாற்றங்கள் நிமிடங்கள் முதல் 48 மணி நேரம் வரை ஆகலாம் (நல்ல வழங்குநருடன் பொதுவாக சில நிமிடங்கள்). பொறுமையாக இருங்கள்.
  • ஒரே பெயரில் A மற்றும் CNAME ஐ கலக்காதீர்கள் – A பதிவுகள் மூலம் ரூட்டை சுட்டிக்காட்டவும், அல்லது துணை டொமைன்களுக்கு CNAME பயன்படுத்தவும்.
  • DNS க்கு முன் HTTPS – சில ஹோஸ்ட்கள் DNS தீரும் வரை சான்றிதழை வழங்காது. வரிசை: முதலில் DNS, பின்னர் HTTPS.
  • GitHub Pages மற்றும் வீட்டு சர்வர்களுடன் பதிவுகளை proxied: off ஆக வைக்கவும் (சாம்பல் கிளவுட்) – Cloudflare-ன் ப்ராக்ஸி நேரடி இணைப்புகளை உடைக்கலாம்.

ஒரு VPS அல்லது வீட்டு நெட்வொர்க்கிற்கான முகவரி வரம்புகளைக் கணக்கிடுகிறீர்களா? எந்த IP/ப்ரிஃபிக்ஸ்க்கும் நெட்வொர்க், பயன்படுத்தக்கூடிய ஹோஸ்ட்கள் மற்றும் ப்ராட்காஸ்ட்டை விநாடிகளில் பெறுங்கள்.

அவ்வளவுதான்

பெயரை சொந்தமாக்குங்கள், சில பதிவுகளைச் சேர்க்கவும், உங்கள் டொமைன் நீங்கள் சொந்தமாக்கும் எங்கும் சுட்டிக்காட்டுகிறது. அது இலவச ஸ்டேடிக் ஹோஸ்டிங், ஒரு வாடகை சர்வர் அல்லது உங்கள் கழுவறையில் உள்ள ஒரு பெட்டியாக இருந்தாலும் – DNS பதிவுகள் பசையாகும், மேலும் அவை எவ்வாறு வேலை செய்கின்றன என்பதை இப்போது உங்களுக்குத் தெரியும்.
