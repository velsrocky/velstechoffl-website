Storalyze (Storage Analyzer) — Privacy Policy

Last updated: Sep 6, 2026

Storalyze ("the app", application ID com.velstech.storalyze) is an offline storage-analysis tool for Android (with limited iOS support). The short version: everything is analyzed on your device — no account, no servers, no ads, and your files are never uploaded anywhere.

1. What the app accesses and why

To show where your storage went, the app reads on-device file metadata (file names, sizes, and dates) and computes duplicate-detection hashes locally. File contents are never read beyond hash sampling and never transmitted.

  • Photos / videos / audio (Android 13+ scoped access): scans media categories with least privilege, only after an in-app explanation and the system permission dialog.
  • All files access (Android 11+): enables a full-device scan including Downloads, WhatsApp media, and Screenshots. Requested only after an in-app rationale screen that also offers a single-folder picker needing no permission at all.
  • Usage access (optional): if you open the system Usage Access settings, the app shows an installed-apps size breakdown. The app works fully without it.
  • File deletion happens only after your explicit per-batch confirmation. There is no remote delete.

2. What we collect

Nothing. There is no analytics SDK, no advertising SDK, and no account system. Scan results live in the app's memory only and are cleared when the app closes.

3. Crash reports (optional)

Release builds may include crash reporting (Sentry). When enabled, a crash sends only the device model, OS version, stack trace, and breadcrumbs — never file contents. Builds without a crash-reporting key log errors locally only.

4. Data sharing

We do not sell, share, or upload your files or personal data to any third party. The only exception is the optional crash trace described above, sent to the crash-reporting provider when that build option is enabled.

5. iOS

On iOS the app is sandboxed: it can only scan its own container or a folder you pick with the document picker. Photo-library access is not requested.

6. Children's privacy

The app is not directed at children under 13 and collects no personal information from anyone.

7. Your choices

  • Deny any permission and use "Pick a folder instead".
  • Revoke access anytime in system Settings → Apps → Storalyze → Permissions.
  • Ask about a crash report by emailing us with the event ID, if shown.

8. Changes to this policy

Material changes will update the date above before rollout.
