Essential terminal commands everyone should know

Terminal Basics Aug 24, 2026 · 7 min read

टर्मिनल देखकर डर सकते हैं, लेकिन यह वास्तव में कंप्यूटर को काम करने के लिए एक टेक्स्ट बॉक्स है। ~20 कमांड्स का उपयोग करें जो लगभग हर किसी को हर दिन करता है। उन्हें सीखें और आप उन्हें हमेशा के लिए उपयोग करेंगे।

पहचानने के तरीके खोजना

pwd              # print working directory – where am I?
ls               # list files in the current folder
ls -la           # list everything, including hidden files (a = all, l = details)
cd folder        # change directory – go into a folder
cd ..            # go up one folder
cd ~             # go to your home folder
cd -             # go back to the previous folder you were in

cd– वो शब्द जो आप सबसे अधिक टाइप करेंगे..मातृ फोल्डर~गृह

2. फ़ाइलों के साथ काम करना 2.1 फ़ाइल प्रकार 2.1.1 टेक्स्ट फ़ाइलें 2.1.2 इमेज फ़ाइलें 2.1.3 ऑडियो फ़ाइलें 2.2 फ़ाइलों को खोलना और बंद करना 2.2.1 फ़ाइलों को खोलने के लिए API 2.2.2 फ़ाइलों को बंद करने के लिए API 2.3 फ़ाइलों को पढ़ना और लिखना 2.3.1 फ़ाइलों को पढ़ने के लिए API 2.3.2 फ़ाइलों को लिखने के लिए API 2.4 फ़ाइलों को संग्रहीत करना 2.4.1 फ़ाइलों को संग्रहीत करने के लिए API 2.5 फ़ाइलों को पुनः प्राप्त करना

cp source dest   # copy a file
mv source dest   # move (or rename) a file
rm file          # delete a file
rm -r folder     # delete a folder and everything inside it (careful!)
mkdir folder     # make a new folder
touch file       # create an empty file
cat file         # print a file's contents
less file        # view a file page by page (q to quit)
nano file        # edit a file in a simple editor (Ctrl+O save, Ctrl+X exit)

3. अनुमतियाँ (क्यों लिनक्स पूछता है कि आप कौन हैं) 4. Linux पर अनुमतियाँ – एक अवलोकन 5. Linux पर उपयोगकर्ता और समूह अनुमतियाँ 6. उपयोगकर्ता अनुमतियाँ और समूह अनुमतियाँ 7. अनुमति सेटिंग्स – उपयोगकर्ता और समूह 8. Linux पर अनुमतियाँ और सुरक्षा 9. Linux पर अनुमतियाँ और सुरक्षा के लिए समाधान

लिनक्स की डिज़ाइन उपयोगकर्ताओं और अनुमतियों के आसपास है। प्रत्येक फ़ाइल का एक मालिक होता है और मालिक, उनके समूह और सभी के लिए पढ़ने, लिखने और निष्पादन के लिए अनुमतियां होती हैं।

ls -l            # shows permissions (like -rw-r--r-- and the owner)
chmod +x file    # make a file executable
chown user file  # change a file's owner
sudo command     # run a command as administrator

sudoसुपरयूजर का उपयोग करना (superuser do) केवल सॉफ्टवेयर इंस्टॉल करने या सिस्टम सेटिंग्स बदलने के लिए है। इसका उपयोग केवल तब किया जाना चाहिए जब कोई कमांड परमिशन एरर के साथ फेल हो जाए और पहले से ही यह पता हो कि कमांड क्या करता है।

चार. सॉफ्टवेयर इंस्टॉल करना (पैकेज मैनेजर्स) पैकेज मैनेजर्स एक ऐसी सॉफ्टवेयर होती है जो कंप्यूटर पर सॉफ्टवेयर इंस्टॉल करने और अपडेट करने की प्रक्रिया को आसान बनाते हैं। यहां कुछ प्रमुख पैकेज मैनेजर्स दिए गए हैं जो विभिन्न प्लेटफ़ॉर्म पर उपयोग किए जाते हैं: - **APT (Advanced Package Tool)**: यह एक प्रमुख पैकेज मैनेजर है जो डेबियन और उसके वेरिएंट पर उपयोग किया जाता है। - **YUM (Yellow Dog Updater, Modified)**: यह एक प्रमुख पैकेज मैनेजर है जो रेड हैट एंटरप्राइज लिनक्स पर उपयोग किया जाता है। - **Zypper**: यह एक प्रमुख पैकेज मैनेजर है जो ओपन एस

Linux में सॉफ्टवेयर को – एक पैकेज मैनेजर – के माध्यम से स्थापित किया जाता हैपैकेज मैनेजरअपने डिस्ट्रो परिवार पर निर्भर करता है:

# Debian / Ubuntu / Mint
sudo apt update && sudo apt upgrade   # update everything
sudo apt install package-name         # install
sudo apt remove package-name          # remove

# Fedora / RHEL family
sudo dnf upgrade                      # update everything
sudo dnf install package-name         # install
sudo dnf remove package-name          # remove

स्थापित करें&&अर्थात् 'पहला चलाएं और यदि वह सफल हो जाए तो दूसरा चलाएं।' पहला अद्यतन करते हुए पैकेज सूची को अद्यतन रखा जाता है।

5. पाइप्स: टर्मिनल की शानदार शक्ति

Kuch bhi|पाइप (एक ट्यूब) एक कमांड के आउटपुट को अगले कमांड में डालता है। यह वह जगह है जहां टर्मिनल जादुई बन जाता है:

ls | wc -l        # count how many files are here
history | tail   # show your recent commands
grep error log.txt   # search a file for "error"
ps aux | grep firefox # find running Firefox processes

grepये अपना एक अलग पदक पाने का हकदार है – यह पाठ के लिए एक पैटर्न खोजता है। आप इसे निरंतर उपयोग करेंगे।

सिस्टम को देखकर

top              # live view of running processes (q to quit)
htop             # friendlier version of top (if installed)
df -h            # how full are my disks? (h = human-readable)
free -h          # how much RAM is in use?
uname -a         # what kernel am I running?
ip a             # my network addresses
ping google.com  # is the internet reachable? (Ctrl+C to stop)
