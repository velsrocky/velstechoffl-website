முகப்பு / இயக்க முறைமைகள் / இந்த கட்டுரை

அனைவரும் தெரிந்திருக்க வேண்டிய அத்தியாவசிய டெர்மினல் கட்டளைகள்

டெர்மினல் அடிப்படைகள் Aug 24, 2026 · 7 நிமிட வாசிப்பு

டெர்மினல் பயமுறுத்துவதாகத் தோன்றுகிறது, ஆனால் அது உண்மையில் உங்கள் கணினிக்கு விஷயங்களைச் செய்யச் சொல்வதற்கான ஒரு உரை பெட்டிதான். இந்த ~20 கட்டளைகள் ஒரு நாளில் யாரும் செய்யும் பெரும்பாலானவற்றை உள்ளடக்குகின்றன. ஒருமுறை கற்றுக் கொள்ளுங்கள், அவற்றை எப்போதும் பயன்படுத்துவீர்கள்.

1. உங்கள் வழியைக் கண்டறிதல்

pwd              # print working directory – where am I?
ls               # list files in the current folder
ls -la           # list everything, including hidden files (a = all, l = details)
cd folder        # change directory – go into a folder
cd ..            # go up one folder
cd ~             # go to your home folder
cd -             # go back to the previous folder you were in

cd தான் நீங்கள் அதிகம் தட்டச்சு செய்வீர்கள். நினைவில் கொள்ளுங்கள்: .. என்பது "பெற்றோர் கோப்புறை" மற்றும் ~ என்பது "முகப்பு".

2. கோப்புகளுடன் பணிபுரிதல்

cp source dest   # copy a file
mv source dest   # move (or rename) a file
rm file          # delete a file
rm -r folder     # delete a folder and everything inside it (careful!)
mkdir folder     # make a new folder
touch file       # create an empty file
cat file         # print a file's contents
less file        # view a file page by page (q to quit)
nano file        # edit a file in a simple editor (Ctrl+O save, Ctrl+X exit)
rm க்கு மீளமைப்பு இல்லை. இது டெர்மினலில் எதையோ வெற்றிடத்தில் இழுப்பதற்கு சமமானதாகும். Enter அழுத்துவதற்கு முன் எப்போதும் பாதையை இருமுறை சரிபார்க்கவும்.

3. அனுமதிகள் (லினக்ஸ் ஏன் நீங்கள் யார் என்று கேட்கிறது)

லினக்ஸ் பயனர்கள் மற்றும் அனுமதிகளைச் சுற்றி கட்டமைக்கப்பட்டுள்ளது. ஒவ்வொரு கோப்பிற்கும் உரிமையாளர் மற்றும் அணுகல் அமைப்புகள் உள்ளன – படிப்பது, எழுதுவது, இயக்குவது – உரிமையாளர், அவர்களின் குழு மற்றும் மற்ற அனைவருக்கும். 

ls -l            # shows permissions (like -rw-r--r-- and the owner)
chmod +x file    # make a file executable
chown user file  # change a file's owner
sudo command     # run a command as administrator

sudo ("சூப்பர்யூசர் டூ") என்பது நீங்கள் மென்பொருளை நிறுவ அல்லது கணினி அமைப்புகளை மாற்ற பயன்படுத்தும் வழியாகும். ஒரு கட்டளை அனுமதி பிழையுடன் தோல்வியுற்றால் மட்டுமே அதைப் பயன்படுத்தவும் – மற்றும் எப்போதும் அந்த கட்டளை என்ன செய்கிறது என்பதை முதலில் தெரிந்து கொள்ளுங்கள்.

4. மென்பொருளை நிறுவுதல் (பேக்கேஜ் மேனேஜர்கள்)

லினக்ஸ் மென்பொருளை ஒரு பேக்கேஜ் மேனேஜர் மூலம் நிறுவுகிறது. கட்டளை உங்கள் டிஸ்ட்ரோ குடும்பத்தைப் பொறுத்தது: 

# Debian / Ubuntu / Mint
sudo apt update && sudo apt upgrade   # update everything
sudo apt install package-name         # install
sudo apt remove package-name          # remove

# Fedora / RHEL family
sudo dnf upgrade                      # update everything
sudo dnf install package-name         # install
sudo dnf remove package-name          # remove

&& என்றால் "முதல் கட்டளையை இயக்கவும், அது வெற்றி பெற்றால், இரண்டாவதை இயக்கவும்". முதலில் புதுப்பிப்பது பேக்கேஜ் பட்டியல்களை தற்போதைய நிலையில் வைத்திருக்கிறது.

5. பைப்புகள்: டெர்மினலின் சூப்பர் பவர்

| எழுத்து (ஒரு பைப்) ஒரு கட்டளையின் வெளியீட்டை அடுத்த கட்டளைக்கு அனுப்புகிறது. இங்குதான் டெர்மினல் மந்திரமாகிறது: 

ls | wc -l        # count how many files are here
history | tail   # show your recent commands
grep error log.txt   # search a file for "error"
ps aux | grep firefox # find running Firefox processes

grep க்கு அதன் சொந்த பதக்கம் தகுதியானது – இது ஒரு மாதிரிக்கான உரையைத் தேடுகிறது. நீங்கள் அதை தொடர்ந்து பயன்படுத்துவீர்கள்.

6. கணினியைச் சுற்றிப் பார்த்தல்

top              # live view of running processes (q to quit)
htop             # friendlier version of top (if installed)
df -h            # how full are my disks? (h = human-readable)
free -h          # how much RAM is in use?
uname -a         # what kernel am I running?
ip a             # my network addresses
ping google.com  # is the internet reachable? (Ctrl+C to stop)

7. நேரத்தை மிச்சப்படுத்தும் விரைவு குறிப்புகள்

  • தானாக முடிக்க Tab – கோப்பு மற்றும் கட்டளை பெயர்களை முடிக்க Tab ஐ அழுத்தவும். ஒவ்வொரு டெர்மினல் பயனரும் இதைச் செய்கிறார்கள்.
  • மேல் அம்பு – முந்தைய கட்டளையை நினைவுபடுத்தவும்.
  • Ctrl+C – இயங்கும் எதையும் ரத்துசெய்யவும்.
  • Ctrl+L – திரையை சுத்தம் செய்யவும்.
  • Ctrl+R – உங்கள் கட்டளை வரலாற்றைத் தேடவும்.
  • man கட்டளை – எந்த கட்டளைக்கும் கையேட்டைப் படிக்கவும் (q வெளியேற).

ஒரு சிறிய உண்மையான உலக அமர்வு

மேலே உள்ள அனைத்தும் ஒன்றாக வேலை செய்வது இங்கே:

$ cd ~/projects
$ mkdir mysite
$ cd mysite
$ touch index.html
$ ls -la
$ nano index.html          # type some HTML, Ctrl+O, Ctrl+X
$ grep -i "title" index.html   # did I write a title?
$ cd ..
$ rm -r mysite            # oops – no undo from here

இவற்றில் எதையும் மனப்பாடம் செய்யத் தேவையில்லை – man மற்றும் Tab விசை உங்களை கொண்டு செல்லும். இவற்றை கையில் வைத்திருங்கள், டெர்மினல் பயமுறுத்துவதை நிறுத்தி உங்களுக்கு பிடித்த கருவியாக மாறும்.
